How the call is made

  1. Strip vig from pregame Avg 1X2 and Avg over/under 2.5.
  2. Convert those into expected full-time goals for each team (Poisson).
  3. Assign 55.5% of expected goals to the second half (historical EPL share).
  4. Predicted FT = HT score + remaining expected 2H goals.
  5. If predicted total ≥ 3.0 → OVER; ≤ 2.0 → UNDER; otherwise NO BET.

Live mode: set workerUrl in config.js after deploying the Cloudflare Worker, or rely on the GitHub Action that refreshes board.json on matchdays. Calls with * are tracking-only (HT window has passed). Not betting advice.
